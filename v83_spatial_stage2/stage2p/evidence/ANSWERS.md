# Stage-2p 五问数据回答（草稿）

## Q1 哪个使 E2E 下降更快？

- MA100 E2E AUC 均值：原始奖励 80.12 ms，方案D 78.70 ms。**方案D** 的整体 AUC 更低。
- 最佳 Dev E2E 均值：原始奖励 59.91 ms，方案D 60.42 ms。

## Q2 哪个末段更稳定、退化更少？

- 最终相对最佳的退化均值：原始奖励 2.15%，方案D 4.04%；末 500 Episode E2E σ 均值：原始奖励 18.31 ms，方案D 18.05 ms。按退化幅度，**原始奖励** 更稳；需与末 500 σ 一起看。
- 按末 500 E2E σ，**方案D** 的波动更小。

## Q3/Q4 D 的收益是否可重复？

- 最佳 Dev E2E: D−Baseline = -1.62, +1.18, +1.99；均值 +0.52，标准差 1.90，D 更好的 seed 数 1/3。
- 最终 Dev E2E: D−Baseline = -1.62, +4.51, +2.19；均值 +1.69，标准差 3.10，D 更好的 seed 数 1/3。
- MA100 E2E AUC: D−Baseline = -3.74, -1.15, +0.61；均值 -1.42，标准差 2.19，D 更好的 seed 数 2/3。
- 最终退化/%: D−Baseline = +0.00, +5.57, +0.11；均值 +1.89，标准差 3.18，D 更好的 seed 数 0/3。
- 末 500 E2E σ: D−Baseline = +0.12, -1.71, +0.79；均值 -0.27，标准差 1.30，D 更好的 seed 数 1/3。

判定：3/3 同向且均值差明显大于 Dev 噪声（Stage-2n 参照 1.26 ms）才算可重复收益；若只有 2/3 或均值差小于噪声，应视为种子依赖/不显著。

## Q5 哪个更接近 Greedy？

- 最佳 Dev 距 Greedy 49.18 ms 的均值：原始奖励 +10.73 ms，方案D +11.24 ms；D 相对 Baseline 的改善为 -0.52 ms。
- 该改善 不大于 Stage-2n 的 Dev 噪声参照 1.26 ms。
